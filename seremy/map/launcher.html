Explore a repository

  1. Connect a local folder, ZIP or HTTPS Git repository.
  2. Expand folders in Files and open a source file.
  3. Select a call, then choose Follow target to visit its declaration.
  4. Use Back to restore your position and selection.

AI documentation

Run the local launcher and connect your MCP agent using the setup guide below. Choose Generate documentation, select a file or folder, add an optional question and copy the request into your agent. Returned drafts appear in Documentation. Their citations open the corresponding source on the map.

Save Markdown downloads a draft. In the local launcher, Save to local path accepts a complete destination filename in an existing folder.
