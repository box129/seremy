# SEREMY Stage 5 metric contracts v1.1.0
Status: FROZEN DEFINITIONS; no scores or benchmark runs.

## Universes and applicability
For each exact snapshot, I=metric_scopes.source; S=metric_scopes.support; T=metric_scopes.all; A=metric_scopes.component_ambiguous; U=I minus A. U is never intersected with output. Layer primary universe is I (component ambiguity does not imply layer ambiguity). Support and complete-inventory coverage are mandatory separately.
Component truth and layer truth are different targets. UA component/hierarchy scores and CodeBoarding layer scores are N/A unless a separately verified producer exists. NDepend executable scores remain N/A.
A metric binding references a frozen snapshot, scope, complete partition (or layers), and optional cut. The registry in stage5-fixture-contracts.json contains the numerator, denominator, missing/extra policies, coherent-alternative policy and N/A rule for every metric below.
Injected-context snapshots permit only mechanism/resource metrics. Their explicit context files define N; they do not acquire semantic truth from the source fixture. Raw-source stability is not calculated between changed synthetic candidate slices.
For pair metrics define P as all unordered distinct pairs on the metric universe (N*(N-1)/2), G+ as reference co-membership pairs and H+ as predicted co-membership pairs. TP=intersection size; FP=H+ minus G+; FN=G+ minus H+. Missing/unassigned files receive distinct placeholder owners only in pair calculations. Conflicting ownership makes the partition invalid; report diagnostics and no invented priority assignment. Unsupported targets are N/A; applicable execution failures are failed runs, never omitted.

## Complete alternatives and missing files
Primary component scores exclude A. Sensitivity scores each entire frozen partition on I and reports the full range. No per-file best-owner selection is permitted. F12 accepted-unassigned reference buckets are singleton placeholders, not semantic components. Its ambiguity acceptance requires the whole probe-set pattern to match a single alternative; mixed per-file choices fail that check.
Inventory recognition does not follow from accepted unassignment: missing files remain missing even when unassignment is permitted. The raw unassigned rate remains visible. Layer scoring includes both F09 adapter and F12 probes because their layer truth is unique.
Extras never enlarge ground truth. Extra paths are reported; extra-only groups are excluded from pair/naming matching on the authored universe but counted as spurious groups diagnostically. Spurious relationships/symbol provenance remain in those provenance denominators.
On absent output, recognition/assignment are zero and unassigned=1 for applicable arms; no parseable partition means pair scores unavailable with a failure flag, not a fabricated zero-quality partition.

## Matching, hierarchy and reporting
Membership matching maximizes the sum of Jaccard over authored-file membership, uses dummy unmatched groups, and only allows positive-Jaccard real matches. For exact ties choose the lexicographically smallest ordered list of (reference group ID,predicted group ID). Name normalization is Unicode casefold plus trim/collapse whitespace; punctuation and word substitutions require a frozen alias. Before matching restrict reference/predicted groups to the declared metric scope and drop empty groups. Accepted-unassigned placeholder groups are excluded from all naming metrics.
Hierarchy is applicable only to F08: source-leaf and source-parent cuts are explicit. Internal-cluster sets use descendant stable file IDs, excluding root, singleton clusters and duplicate unary sets. Invalid cycles/multiple parents invalidate hierarchy metrics and are counted, not silently repaired. Missing files remain in reference clusters.
Dependency retention counts unique directed authored file-pair interactions crossing the selected reference components. An unresolved/conflicting endpoint fails the numerator but stays in the denominator. No membership-based group-name match is required for boundary retention. Report structural and semantic/HTTP/event contracts separately; extraction recall is a distinct observation diagnostic.
For repeat/change comparisons use common unchanged stable IDs, excluding component-ambiguous IDs only for component stability. Pair disagreement is symmetric difference divided by all eligible pairs; fewer than two files yields N/A. Name stability matches each run separately to frozen reference groups; unmatched groups fail. Evaluate full/full and incremental/full pairs separately. No invariance demand for changed semantic truth.
Report rates with raw numerator/denominator, valid-run count and scheduled-run count. Macro means use applicable computed cases with explicit missing/failure counts; never present a success-only mean without those counts. Pooled TP/FP/FN is a separate size-weighted view. No combined winner score.
Runtime denominators are one run. Include retries, separate setup/cold/warm state, use monotonic wall time. Peak memory is max sampled process-tree RSS sum at simultaneous samples; record interval and unsupported measurement. CPU and provider token/call counts require recorded actual measurements. No price-derived cost metric is frozen.
Predeclared observations without a numeric score: unexpected generated paths, exported metadata fields, source/parser omissions, duplicate ownership, invalid hierarchy, success/failure reasons. These diagnostics have explicit raw counts or statuses and must not be converted to accuracy scores.
Source tree hashes are null until source exists. Later source review and tool observations are outside Task 4B; missing measurements are not fabricated zeroes.
